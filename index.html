سياسة الخصوصية

آخر تحديث: يوليو 2026

نلتزم في VideoSearch Pro بحماية خصوصيتك. توضح هذه السياسة كيفية تعاملنا مع بياناتك عند استخدامك للموقع.

1. المعلومات التي نجمعها

لا نجمع أي معلومات شخصية تعريفية. عمليات البحث التي تُجريها لا يتم تخزينها على خوادمنا. نستخدم YouTube Data API v3 وفق سياسة خصوصية Google.

2. كيفية استخدام البيانات

  • تُستخدم استعلامات البحث فقط للحصول على نتائج من YouTube API وتُرسل مباشرةً إلى Google.
  • لا نشارك أي بيانات مع أطراف ثالثة.
  • لا نستخدم ملفات تعريف الارتباط (Cookies) لأغراض التتبع.

3. ملفات تعريف الارتباط

نستخدم localStorage فقط لحفظ تفضيل الوضع المظلم/الفاتح. لا يتم تخزين أي بيانات حساسة.

4. روابط الطرف الثالث

قد يحتوي الموقع على روابط لمواقع خارجية (YouTube). نحن غير مسؤولين عن سياسات الخصوصية لتلك المواقع.

5. أمان البيانات

نتخذ تدابير تقنية معقولة لحماية الموقع، ولكن لا يوجد نظام آمن بنسبة 100%.

6. التواصل معنا

لأي استفسار يتعلق بالخصوصية، يرجى التواصل معنا عبر صفحة اتصل بنا.
